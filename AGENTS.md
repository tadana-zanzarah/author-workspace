# Правила дальнейшей разработки

- Архитектурная основа проекта — `reference/author_workspace_v11_stage3.html`.
- `reference/author_workspace_v10.html` используется только как справочник поведения; откат к V10 запрещён.
- Папка `backup` неприкосновенна: не изменять, не перемещать и не удалять её содержимое.
- Исходные файлы в `reference` не редактировать.
- Сцены, персонажи и отношения должны опираться на устойчивые `id`, а не на индексы или имена.
- Нельзя ломать миграцию старых данных, менять ключи `localStorage` без безопасной миграции или автоматически очищать пользовательские данные.
- Перед крупными изменениями проверять загрузку из `localStorage`, импорт и экспорт JSON.
- Новые функции добавлять отдельными небольшими этапами с проверкой после каждого этапа.
- Не сокращать существующее поведение ради формальной чистоты архитектуры.
