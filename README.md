# Авторское рабочее пространство

Это локальное браузерное приложение. Рабочая модульная версия находится в корне проекта.

## Как открыть приложение

Главный файл — `index.html`. Поскольку приложение использует обычные браузерные ES-модули, некоторые браузеры не разрешают запуск всех модулей двойным щелчком по файлу. Надёжный способ — открыть папку проекта в терминале и запустить простой локальный сервер:

```powershell
node tools/server.mjs
```

После этого откройте в браузере адрес:

```text
http://localhost:8000/
```

Чтобы остановить сервер, вернитесь в окно терминала и нажмите `Ctrl+C`.

## Где находятся эталонные версии

Исходные версии V10 и V11 находятся в папке `reference`. Они нужны для сравнения и не должны редактироваться. Архитектурной основой является `reference/author_workspace_v11_stage3.html`; V10 используется только как справочник поведения.

Папка `backup` и любые файлы внутри неё неприкосновенны: их нельзя изменять, перемещать или удалять. Не удаляйте также папку `reference`.

## Как сделать резервную копию данных

В приложении откройте меню «Проект» и нажмите «Экспорт JSON». Браузер скачает файл с данными проекта. Храните его отдельно от папки приложения. Для восстановления используйте пункт импорта JSON в том же меню.

Данные также автоматически сохраняются браузером в `localStorage`. Они связаны с адресом, по которому открыто приложение, поэтому рекомендуется запускать сервер всегда на одном и том же порту.

## Защита данных и безопасный импорт

Перед загрузкой приложение отдельно проверяет структуру проекта, определяет версию и только затем выполняет миграцию и нормализацию. Пустой объект `{}`, неизвестная версия, дубли ID и повреждённые ссылки не превращаются в новый пустой проект.

Если основная база V11 повреждена или вызывает критический конфликт, её исходная строка остаётся в `localStorage` без изменений, а обычное сохранение блокируется. В меню проекта появляется кнопка «Скачать проблемный JSON». Сначала скачайте этот файл; затем можно проверить резервную копию отдельно. Найденная старая база не записывается поверх повреждённой V11 автоматически.

Импорт JSON выполняется в два шага: сначала файл проверяется без изменения текущего проекта, затем приложение показывает краткий отчёт и просит подтверждение. Только после подтверждения и успешной записи импорт заменяет текущие данные.

При ошибке сохранения (например, переполнении памяти браузера или запрете доступа к `localStorage`) изменение не применяется к подтверждённому состоянию. Редактор остаётся открытым, чтобы введённые значения можно было скопировать или повторить сохранение. Технический стек пользователю не показывается.

Для обычной резервной копии регулярно нажимайте «Экспорт». Храните скачанный JSON отдельно от папки приложения, особенно перед импортом большого проекта или добавлением фотографий.

## Если проект не открывается

Если основная база повреждена или найдено несколько возможных резервных версий, приложение открывает окно безопасного восстановления. Ничего не заменяется автоматически — даже если подходящая копия только одна.

Сначала нажмите «Скачать повреждённую основную базу». Затем выберите найденную версию: рядом показаны её ключ в браузере, версия и количество сцен, персонажей, глав, локаций и тегов. Можно отдельно скачать исходный JSON кандидата и предварительную V11. Кнопка восстановления становится доступной только после успешной предварительной проверки и явного подтверждения. Перед заменой приложение сохраняет исходную основную базу под отдельным ключом с датой и временем. Если запись не удалась, активный проект и исходная база остаются прежними.

Если в старой V10 есть два персонажа с одинаковым именем, приложение показывает каждую неоднозначную ссылку и обоих кандидатов с их ID, фамилией и описанием, если эти сведения есть. Выберите нужного персонажа для каждой ссылки. Пока хотя бы одна ссылка не сопоставлена, миграцию применить нельзя.

## Даты сцен

Отметка «Дата ещё не проверена» означает, что дата или время менялись, сцена переносилась либо импорт содержал сомнительное значение. Кнопка «Дата проверена» снимает только эту пользовательскую отметку. Она не скрывает отдельное сообщение «Дата конфликтует с хронологией соседних сцен» — такой конфликт вычисляется объективно по соседним сценам.

Календарные даты и время проверяются строго. Например, `2026-02-31` и `24:00` не превращаются браузером в другие значения: исходная строка сохраняется, сцена помечается для проверки, а хронология её не использует.
## Несохранённые изменения

Приложение предупреждает перед закрытием изменённой формы. Кнопка «Продолжить редактирование» возвращает в форму и сохраняет весь введённый черновик, включая текст и добавленные фотографии. «Закрыть без сохранения» закрывает редактор и оставляет в проекте последнюю успешно сохранённую версию.

Если браузеру не удалось сохранить проект, редактор остаётся открытым, введённые значения не очищаются, а предупреждение продолжает действовать. Сохранение можно повторить после устранения причины ошибки. При обновлении или закрытии вкладки браузер также показывает стандартное предупреждение, если хотя бы одна открытая форма действительно отличается от сохранённого состояния.
